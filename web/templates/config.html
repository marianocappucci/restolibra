credit_cardMercadoPago ¿Cómo obtener el Access Token, User ID, POS ID y Webhook Secret? expand_more

1 — Access Token (token de producción)

  1. Ingresá a mercadopago.com.ar/developers/panel/app open_in_new
  2. Creá una nueva aplicación (o seleccioná una existente)
  3. En la aplicación, andá a la pestaña Credenciales de producción
  4. Copiá el Access token (empieza con APP_USR-) y pegalo abajo

2 — User ID del vendedor

  1. Iniciá sesión en mercadopago.com.ar open_in_new
  2. Hacé clic en tu avatar (arriba a la derecha) → Tu perfil
  3. El User ID es el número que aparece abajo de tu nombre (ej: 123456789)
  4. También lo encontrás en el panel de desarrolladores al ver las credenciales de tu app

3 — POS ID (External ID del punto de venta)

  1. En mercadopago.com.ar/stores open_in_new creá o seleccioná una Sucursal
  2. Dentro de la sucursal, creá un Punto de venta (tipo: PDV)
  3. Al crearlo, completá el campo External ID con un código propio (ej: CAJA01) — ese valor es el que va acá

4 — Webhook Secret

  1. En el panel de desarrolladores, entrá a tu aplicación y luego a Webhooks
  2. Registrá la URL: https://tu-dominio/webhooks/mercadopago y seleccioná el evento Pagos (payment)
  3. MercadoPago te mostrará una firma secreta (secret) — copiala y pegala en el campo Webhook Secret
warning Usá siempre las credenciales de producción, no las de prueba, para cobros reales.

securityARCA / AFIP ¿Cómo obtener el certificado digital y la clave privada? expand_more

1 — Generar la clave privada y el CSR (en tu PC)

  1. Instalá OpenSSL (en Windows podés usar Git Bash o WSL; en Linux/Mac ya viene incluido)
  2. Abrí una terminal y ejecutá:
    openssl genrsa -out clave_privada.key 2048
  3. Luego generá el CSR (pedido de certificado):
    openssl req -new -key clave_privada.key -subj "/C=AR/O=Mi Empresa/CN=CUIT 20123456789" -out mi_empresa.csr Reemplazá CUIT 20123456789 con tu CUIT sin guiones.
  4. Guardá bien el archivo clave_privada.key — es el que subís al campo Clave privada de abajo

2 — Obtener el certificado desde el portal ARCA

  1. Ingresá con CUIT y Clave Fiscal (nivel 3 o superior) a auth.afip.gob.ar open_in_new
  2. Buscá el servicio "Administración de Certificados Digitales" en el listado de servicios habilitados
  3. Hacé clic en Nueva solicitud de certificado
  4. Pegá el contenido del archivo mi_empresa.csr generado en el paso anterior
  5. Descargá el certificado resultante (.crt o .pem) — ese archivo es el que subís al campo Certificado de abajo

3 — Punto de venta

  1. En el portal ARCA / AFIP, buscá el servicio "ABM de Puntos de Venta"
  2. Creá un punto de venta de tipo Facturación electrónica — Web Services
  3. El número asignado es el que ingresás en el campo Punto de venta de abajo (ej: 5)
info Usá el ambiente Homologación para hacer pruebas sin emitir comprobantes reales. Cambiá a Producción recién cuando todo funcione correctamente.
warning La clave privada nunca se comparte ni se sube a ningún sitio externo. Solo la subís una vez a este servidor, que es tuyo.

badgeARCA / AFIP ¿Qué servicio debo habilitar para consultar datos de clientes por CUIT? expand_more

El botón "Consultar ARCA" en el formulario de clientes completa automáticamente nombre, domicilio y condición de IVA a partir del CUIT. Para que funcione, tu certificado debe tener acceso al webservice de Padrón Alcance 13.

1 — Ingresar al Administrador de Relaciones

  1. Ingresá con CUIT y Clave Fiscal a auth.afip.gob.ar open_in_new
  2. Buscá y abrí el servicio "Administrador de Relaciones de Clave Fiscal"
  3. Hacé clic en Nueva Relación

2 — Crear la relación para Padrón Alcance 13

  1. En Servicio, buscá y seleccioná: Consulta a Padrón Alcance 13 (ws_sr_padron_a13)
  2. En Representante, seleccioná el certificado que ya configuraste en Restolibra
  3. Confirmá la relación
check_circle Una vez habilitado, el botón "Consultar ARCA" en el alta de clientes funcionará automáticamente.
info Este servicio es distinto al de facturación (WSFE). Necesitás habilitarlos por separado usando el mismo certificado.

open_in_newGmail ¿Cómo configurar Gmail con una contraseña de aplicación? expand_more

Gmail no permite usar tu contraseña normal para enviar emails desde apps externas. Necesitás generar una contraseña de aplicación de 16 caracteres. Seguí estos pasos:

  1. Ingresá a tu cuenta de Google en myaccount.google.com open_in_new
  2. En el menú izquierdo hacé clic en Seguridad
  3. Asegurate de tener activada la Verificación en dos pasos (es un requisito de Google)
  4. Buscá "contraseñas de aplicación" en el buscador de configuración de Google o ingresá directamente a myaccount.google.com/apppasswords open_in_new
  5. En el campo Nombre de la app escribí Restolibra y hacé clic en Crear
  6. Google te mostrará una contraseña de 16 caracteres — copiala en ese momento (no se vuelve a mostrar)
  7. Pegá esa contraseña en el campo Contraseña del formulario de abajo y guardá
info Valores recomendados para Gmail:  Servidor: smtp.gmail.com  ·  Puerto: 587  ·  Usuario: tu dirección de Gmail completa
