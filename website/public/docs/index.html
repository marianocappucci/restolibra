Documentación de Contalibra

Todo lo que necesitás saber para aprovechar al máximo el sistema. Desde la configuración inicial hasta el uso diario de cada módulo.

Por dónde empezar

Si es la primera vez que accedés a Contalibra, seguí esta secuencia:

  1. Ingresá al sistema con las credenciales que te proporcionó el administrador.
  2. Completá los datos de tu empresa — razón social, CUIT, dirección, logo.
  3. Configurá los módulos que necesitás según tu plan.
  4. Cargá tus productos o servicios para poder hacer ventas y presupuestos.
  5. Abrí tu primer turno de caja y registrá tu primera venta.
